🤖 # MR-Project – Cooperative Autonomous Exploration with RGB-D Robots
________________________________________
📌 ## Project Overview
This repository contains the implementation of a multi-robot autonomous exploration system. The project is based on ROS 2 Jazzy and Gazebo and involves two TurtleBot3 Burger robots equipped with LiDAR and RGB-D sensors.
The robots autonomously explore an unknown indoor environment using frontier-based exploration, build a map through SLAM Toolbox, navigate using Nav2, and detect specific objects using a YOLO-based object detection pipeline. Detected objects are filtered, localized in the global map frame, and visualized in RViz2 through a centralized coordination node.

▶️ ## First-time setup
1️⃣ Clone Explore Lite
cd ros_ws/src/
git clone https://github.com/robo-friends/m-explore-ros2.git
________________________________________
2️⃣ Build the Docker Image 
cd ../../docker_ws/
chmod +x build_project.sh
./build_project.sh
________________________________________
3️⃣ Make Scripts Executable
cd ..
chmod +x run.sh exec.sh chown_me.sh
________________________________________
▶️ ## How to Run the Project
1️⃣ Start the Docker Container
./run.sh
________________________________________
2️⃣ Build and Source the ROS 2 Workspace
Inside the container:
colcon build
source install/setup.bash
________________________________________
3️⃣ Launch Simulation and SLAM
Run the first launch file
ros2 launch custom_pkg first.launch.py
________________________________________
4️⃣ Launch Navigation and Exploration
Open a second terminal, attach it to the same container, and run:
./exec.sh
source install/setup.bash
ros2 launch custom_pkg second.launch.py
________________________________________
🧠 ## YOLO Training and Custom Dataset
Since standard YOLO datasets do not include simple geometric shapes, a custom dataset was created using Roboflow.
To retrain the model:
1.	Modify or replace the dataset in ros_ws/src/yolo/
2.	Run:
python3 train_yolo.py
3.	Update the model file used by the yolo_node
Cambiare mondo(?)
-	Cambiare posizioni iniziali nei launch first e gazebo_moltirobo
-	Cambiare nome del file sdf nel gazebo_multirobot
Se vogliamo usare la GPU per velocizzare aggiungere nel file run.sh la riga     --runtime nvidia --gpus all\

🔄 ## Changing World or Robot Configuration
To change the simulation scenario:
•	Modify the initial robot positions in first.launch.py and gazebo_multirobot.launch.py
•	Change the SDF world file name inside gazebo_multirobot.launch.py
⚠️ The current implementation is designed for exactly two robots. To add more robots, additional URDF/SDF models and corresponding configurations must be created
________________________________________
🚀 ## GPU Acceleration (Optional)
To enable GPU support for YOLO inference and speed up computation, add the following line to run.sh:
--runtime nvidia --gpus all \
`main.launch.py` VERIFICA
Make sure NVIDIA drivers and NVIDIA Container Toolkit are correctly installed on your system.
