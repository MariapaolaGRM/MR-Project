# 🤖  Cooperative Autonomous Exploration with RGB-D Robots
________________________________________
## 📌  Project Overview
This repository contains the implementation of a **multi-robot autonomous exploration** system. The project is based on **ROS2 Jazzy** and **Gazebo** and involves two **TurtleBot3 Burger** robots equipped with LiDAR and RGB-D sensors. <br>
The robots autonomously explore an unknown indoor environment using frontier-based exploration, build a map through **SLAM Toolbox**, navigate using **Nav2**, and detect specific objects using a **YOLO**-based object detection pipeline. Detected objects are filtered, localized in the global map frame, and visualized in **RViz2** through a centralized coordination node.

### **ros_ws/src:**

•	**turtlebot3_gazebo** <br>
  Adapted from [ROBOTIS-GIT/turtlebot3_simulations](https://github.com/ROBOTIS-GIT/turtlebot3_simulations), includes robot models and launch files to spawn the TurtleBot3 in a Gazebo simulation and enable communication with ROS.<br>
  - Added 2 different model files, one for each robot.
  - Added 2 different urdf files, one for each robot.
  - Updated bridge file duplicating all the bridges by adding robot’s namespace before the topics.

•	**custom_pkg** <br>
Custom package created for the project, which includes nodes, launch and configuration files.

```
Custom_pkg/
├── config/                           # Configuration files for explore lite, nav2, slam_toolbox

│   ├── nav2_config.yaml

│   ├── first.launch.py
```

Custom package which includes the definition of a message that defines the x,y coordinates of the center of the bounding boxes, the width w, and the height h. It also includes the header frame of the robots from which the message originates.

## ▶️ First-time setup
1️⃣ Clone Explore Lite
```bash
cd ros_ws/src/
git clone https://github.com/robo-friends/m-explore-ros2.git
```

2️⃣ Build the Docker Image 
```bash
cd ../../docker_ws/ 
chmod +x build_project.sh 
./build_project.sh
```

3️⃣ Make Scripts Executable
```bash
cd ..
chmod +x run.sh exec.sh chown_me.sh
```
________________________________________
## ▶️ How to Run the Project
1️⃣ Start the Docker Container
```bash
./run.sh
```

2️⃣ Build and Source the ROS 2 Workspace
Inside the container:
```bash
colcon build
source install/setup.bash
```

3️⃣ Launch Simulation and SLAM
Run the first launch file
```bash
ros2 launch custom_pkg first.launch.py
```

4️⃣ Launch Navigation and Exploration
Open a second terminal, attach it to the same container, and run:
```bash
./exec.sh
source install/setup.bash
ros2 launch custom_pkg second.launch.py
```

## 🧠 YOLO Training and Custom Dataset
Since standard YOLO datasets do not include simple geometric shapes, a custom dataset was created using Roboflow.

To retrain the model:
1.	Modify or replace the dataset in ros_ws/src/yolo/
2.	Run:
```python3 train_yolo.py```
3.	Update the model file used by the yolo_node

## 🔄 Changing World or Robot Configuration
To change the simulation scenario:

•	Modify the initial robot positions in first.launch.py and gazebo_multirobot.launch.py <br>
•	Change the SDF world file name inside ```gazebo_multirobot.launch.py``` <br>
• Choose the correct number of object in the Central Node (line 164/165)

⚠️ The current implementation is designed for exactly two robots. To add more robots, additional URDF/SDF models and corresponding configurations must be created
________________________________________
## 🚀 GPU Acceleration 
To enable GPU support for YOLO inference and speed up computation, add the following line to run.sh:<br>
```
--runtime nvidia --gpus all \
```
Make sure NVIDIA drivers and NVIDIA Container Toolkit are correctly installed on your system.

If you do not need the 3D viewer, comment-out the gzclient_cmd block in ```gazebo_multirobot.launch.py```.
